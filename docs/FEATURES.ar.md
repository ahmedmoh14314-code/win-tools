# WinTools: المميزات وحالتها

هذا الملف للفريق: ماذا يفعل WinTools، ما الذي أُنجز ولماذا، ما الذي أُخفي من هذا الإصدار، وما الذي لم يُنجز بعد.

آخر تحديث: 2026-11-11. الإصدار الحالي للتجربة: **0.2.2 Beta**، وهو غير منشور كإصدار رسمي على GitHub ولا يوجد له Tag.

---

## 1. ما هو WinTools

أداة ويندوز لتحويل الملفات ومعالجتها بسرعة، بدون فتح أي برنامج:

1. تسحب ملفًا أو أكثر في Explorer.
2. تضغط **Space** (أو مفتاحًا تختاره) وأنت ما زلت ممسكًا بالملف.
3. تظهر عجلة فيها الأوامر المناسبة لنوع الملف فقط.
4. تفلت الملف على الأمر، فيُحفظ الناتج بجانب الأصل.

### مبادئ ثابتة في كل الأوامر

| المبدأ | لماذا |
|---|---|
| **الملف الأصلي لا يُمس أبدًا** | الناتج يُكتب في ملف مؤقت، يُفحص، ثم يُنقل باسم جديد مثل `report (1).pdf`، ولا يُكتب فوق أي ملف موجود. |
| **كل شيء على الجهاز، بدون إنترنت** | لا حساب، لا سحابة، لا إرسال بيانات. خصوصية المستخدم أولًا. |
| **كل ملف يُعامل كأنه خطر محتمل** | يُفحص نوع الملف من محتواه لا من امتداده، والمعالجة تتم في عمليات منفصلة (Workers)، فلو انهار ملف تالف لا ينهار التطبيق. |
| **لا Administrator** | يعمل بصلاحيات المستخدم العادي. |
| **لا GPL/AGPL** في المنتج | كل مكتبة مضمّنة مرخّصة بما يسمح بالاستخدام التجاري، ومسجلة في `docs/architecture/dependency-matrix.md`. |
| **عربي وإنجليزي** | الواجهة كاملة باللغتين، والعربي من اليمين لليسار. |

## 2. المميزات المنجزة والموجودة في التطبيق

### الصور

| الميزة | ملاحظات |
|---|---|
| تحويل بين JPG وPNG وWebP وBMP وTIFF، وإلى AVIF | |
| قراءة HEIC وAVIF (صور الآيفون) | عبر FFmpeg المضمّن. |
| ضغط، تغيير الحجم، تدوير، قلب، قص بنسب جاهزة | |
| تعديلات بنقرة واحدة | |

| إزالة البيانات الوصفية (الموقع، الكاميرا…) | للخصوصية. |
| صور إلى PDF | صفحة لكل صورة. |

### PDF

| الميزة | ملاحظات |
|---|---|
| دمج، تقسيم إلى صفحات، تدوير | عبر qpdf. |
| تعديل الصفحات: ترتيب، تدوير، تكرار، حذف، استخراج | نافذة تعرض صور الصفحات. |
| تصغير بدون فقدان جودة، Fast web view، إصلاح | |
| حماية بكلمة سر، وفك الحماية | كلمة السر لا تُكتب في أي سجل. |
| معلومات PDF | |
| PDF إلى PNG وJPG وTXT وMarkdown | عبر PDFium المضمّن. |
| **PDF إلى PowerPoint (جديد)** | كل صفحة شريحة كصورة. لا يحتاج أي برنامج. |
| **PDF إلى Word (جديد)** | يحتاج Microsoft Word أو LibreOffice. |
| **PDF إلى Excel (جديد)** | يعيد بناء الجداول من نص الـPDF. |

### مستندات Office والويب

| الميزة | ملاحظات |
|---|---|
| **Word وPowerPoint وExcel إلى PDF (محسّن)** | يستعمل Microsoft Office الموجود على الجهاز، وإن لم يوجد يستعمل LibreOffice. |
| **صفحة ويب (HTML) إلى PDF (جديد)** | عبر Edge الموجود في ويندوز، مع منع السكربتات والإنترنت. |
| CSV وTSV إلى Excel، وExcel إلى CSV | |
| Markdown إلى HTML | |
| استخراج النص، إزالة خصائص المستند، معلومات المستند | |

### الفيديو والصوت (عبر FFmpeg بترخيص LGPL)

تحويل، ضغط، قص بالوقت، تقسيم، قص الإطار، دمج، تغيير السرعة، استخراج الصوت أو إزالته، حفظ إطارات، توحيد مستوى الصوت، Mono/Stereo، ومعلومات الملف.

### الأرشيفات

فك ZIP (والمحمي بكلمة سر) وTAR وTAR.GZ وGZIP، وفك 7z وRAR، واختبار الأرشيف، وإنشاء ZIP. توجد حماية من مسارات خبيثة داخل الأرشيف ومن الأرشيفات المتضخمة (Zip bomb).

### الترجمات

تحويل بين SRT وVTT، تقديم وتأخير التوقيت، إصلاح الترميز إلى UTF-8، ومعلومات الملف.

### الملفات

نسخ المسار أو الاسم أو المجلد، نقل إلى، نسخ إلى، إظهار في المجلد، فتح في Terminal، إعادة تسمية دفعة ملفات، وSHA-256.

### الاستخدام

مفتاح التشغيل Space افتراضيًا، أو F7 أو F9 أو F12 أو أي حرف من A إلى Z. الحرف يعمل فقط أثناء سحب ملف، حتى لا يتعارض مع الكتابة العادية.

## 3. ما أُضيف في الدفعة الأخيرة، ولماذا

| الميزة | لماذا أُضيفت | كيف تحققنا منها |
|---|---|---|
| **Office إلى PDF عبر Microsoft Office** | أغلب المستخدمين عندهم Office وليس LibreOffice، والنسخة السابقة كانت تخفي الأمر بدونه. | تجربة حقيقية على Microsoft 365: عرض PowerPoint وملف Word وملف Excel تحولت كلها إلى PDF، ولم يبقَ أي برنامج Office مفتوحًا بعدها. |
| **PDF إلى Word** | مطلوب من صاحب المنتج، ومن أشهر أدوات iLovePDF. | تجربة حقيقية عبر Word: PDF من 3 صفحات صار ملف Word. |
| **PDF إلى PowerPoint** | يعمل على أي جهاز بدون برنامج إضافي. | فُتحت الملفات الناتجة في PowerPoint الحقيقي بدون رسالة إصلاح، وبعدد الشرائح والمقاس الصحيح. |
| **HTML إلى PDF** | من أدوات iLovePDF. Edge موجود في كل ويندوز. | تجربة حقيقية: صفحة فيها عربي وإنجليزي طُبعت صحيحة، ولم يعمل السكربت الموجود فيها، ولم تُحمّل الصورة من الإنترنت. |
| **PDF إلى Excel** | من أدوات iLovePDF. | جدول عربي وجدول إنجليزي طبعهما Excel إلى PDF، ثم رجعت كل خلية في عمودها الصحيح، بما فيها كلمات مثل «عمّان» و«المدينة». |

### ملاحظات صريحة على الجودة

- **PDF إلى Word:** النص يصبح قابلًا للتعديل، لكن الصفحات المعقدة لا تطابق الأصل في الشكل. لا يوجد محرك مجاني أفضل من Word نفسه.
- **PDF إلى PowerPoint:** الشرائح صور، والنص فيها غير قابل للتعديل. اخترنا ذلك لأنه يعمل على كل جهاز بدون برنامج إضافي.
- **PDF إلى Excel:** يعمل جيدًا مع الجداول المرسومة بحدود ومع الجداول البسيطة. لا يفهم الخلايا المدموجة، ولا يعمل على الصفحات الممسوحة ضوئيًا لأنها صور بدون نص.

## 5. لم يُنجز بعد

| الميزة | السبب |
|---|---|
| إخفاء نص نهائيًا (Redact) | مؤجل: ليس تحويلًا. |
| تعديل PDF بإضافة نص وصور | مؤجل: يحتاج محرّرًا كاملًا. |
| مقارنة ملفي PDF | مؤجل. |
| OCR (قراءة النص من الصفحات الممسوحة) | وافق صاحب المنتج عليه مبدئيًا. يعمل بمحرك ويندوز المجاني بدون إنترنت، لكنه يزيد حجم التطبيق حوالي 25 ميجابايت. |
| PDF/A | لا يوجد محرك مجاني يسمح ترخيصه بالاستخدام التجاري. Ghostscript ترخيصه AGPL، وهو ممنوع عندنا. |
| الترجمة والتلخيص بالذكاء الاصطناعي | يحتاج إنترنت وسيرفرات، وهذا يخالف مبدأ العمل بدون إنترنت. |

| الكتابة على الصور، إزالة الخلفية، الرف العائم، SVG، ترجمات ASS، إنشاء 7z | مؤجلة. |
| إعدادات افتراضية للفيديو والصوت وPDF | الإعدادات الحالية هي: اللغة، المفتاح، البدء مع ويندوز، مكان الحفظ، وجودة الصور. |

## 6. الجودة والاختبار

- **CI على GitHub:** يبني المشروع ويشغّل كل الاختبارات قبل أي دمج. لا يُدمج PR إلا بعد نجاحه.
- **عدد الاختبارات:** حوالي 720 اختبارًا للمنطق (Core)، ومئات أخرى للتحويلات والعمليات المنفصلة (Workers).
- **اختبار الواجهة:** يتأكد آليًا أن كل اسم أمر يتسع في مكانه على العجلة بكل أحجام الشاشة. بسبب هذا الاختبار صار اسم الأمر «To PPTX» بدل «To PowerPoint».
- **التجارب الحقيقية:** كل ميزة جديدة جُرّبت على برامج حقيقية على جهاز التطوير، كما في جدول القسم 3.
- **فحص الفيروسات:** فُحص ملف التثبيت ومجلد البرنامج بـ Windows Defender، ولم تُوجد أي تهديدات. وراجعنا الكود، فلا يوجد فيه أي اتصال بالإنترنت أو تنزيل.

### لم يُختبر بعد

- التثبيت على جهاز نظيف، وإلغاء التثبيت.
- مراجعة كاملة للواجهة بالعربية والإنجليزية.
- السحب الحقيقي من Explorer لبعض الأوامر: تعديل الصفحات، 7z وRAR، HEIC، النقل والنسخ، والتحويلات الجديدة.
- التحويلات عبر LibreOffice الحقيقي، لأنه غير مثبت على جهاز التطوير.

## 7. تنبيهات للفريق

- **ملف التثبيت غير موقّع رقميًا:** سيظهر تحذير SmartScreen عند التثبيت. الحل الدائم شراء شهادة توقيع.
- **FFmpeg:** الموقع الذي كنا ننزّله منه يحذف النسخ القديمة، فحفظنا نسخة مطابقة (نفس البصمة) في إصدار منفصل على GitHub اسمه `engines-ffmpeg-8.1.3`. هذا ليس إصدارًا لـ WinTools.
- **Edge وOffice وLibreOffice:** لا يثبّتها WinTools ولا ينزّلها أبدًا. يستعمل الموجود منها على الجهاز، ويخفي الأمر إن لم يجد البرنامج المطلوب.
- **أسماء الأوامر قصيرة عمدًا** حتى تتسع في العجلة: «To PPTX» و«To XLSX».
